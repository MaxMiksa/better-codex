# 阅读宽度、字号与表格增强（`reading`）

负责主/侧聊天阅读排版增强：正文宽度、AI 回复字号、聊天标题居中、原生文件页路径栏防抖、助手 Markdown 表格自适应列宽居中与临时多列排序。

## 交互与口径契约

- **正文宽度与字号**：宽度支持 768–1600 px（滑杆步长 16px，输入框回车或失焦提交）；AI 回复字号支持 10–40 px（留空跟随原生），仅作用于助手回复，不影响用户消息、输入框或侧栏。
- **聊天标题与路径栏**：聊天标题默认按主面板居中，窄窗优先保留截断不挤占两侧按钮；原生文件页路径栏按工具栏分配宽度决定省略，消除固定宽度下反复闪动。
- **表格排版与排序**：独立于正文宽度，按实际几何尺寸动态分配列宽并支持居中（上限受面板与 `min(80em, 1440px)` 约束）；点击表头按“首选 → 反向 → 原序”循环，`Ctrl+点击` 多列优先级排序，`Alt+点击` 预设或反向；仅视觉平移原始行，不改动 DOM 行序、Markdown 或复制结果。文件预览中的虚拟化 CodeMirror 表格不在支持范围内。

## 模块与验证

- `ui/`：`reading-width.ts`、`reading-width.css`、`table-sort.ts`、`table-sort.css`、`table-sort-control.css`
- `host/`：`Set-ReadingWidth.ps1`
- 校验命令：`width`、`table-sort`、`multi-window`
