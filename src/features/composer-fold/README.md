# 输入框自动隐藏（`composer-fold`）

在已有本地聊天中自动收起空白主输入框（支持“最小化”和“完全隐藏”两种样式），为阅读留出更多纵向空间，同时保持直接打字、中文输入法组字与正文拖选零阻力。

## 交互与口径契约

- **收起条件**：仅对已确认的已有聊天空白主输入框生效；空白新聊天、未发送草稿、附件、录音与原生待确认卡片始终保持展开。支持可选子开关「发送后自动隐藏」及空输入框按 `Esc` 立即收起。
- **展开与输入法**：
  - 两种样式均支持直接在正文区打字展开（从首个拼音字母即进入原生编辑器组字，展开动画不打断光标与组字）或连按两次 `Enter` 展开聚焦；最小化模式另提供「展开输入框」按钮。
  - 鼠标拖选聊天正文时让出焦点，选中期间不抢回焦点，取消选中后可继续直接打字；系统开启“减少动态效果”时直接切换不播动画。
- **原生状态兼容**：底部原生文件变更胶囊在收起时保持可见（最小化模式与展开按钮并排），不影响正文内变更卡片与侧栏右键菜单。

## 模块与验证

- `ui/`：`composer-fold.ts`、`composer-fold.css`
- 校验命令：`composer-fold`、`multi-window`
