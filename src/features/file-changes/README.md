# 文件更改卡片收起（`file-changes`）

默认将聊天正文中的多文件更改卡片收起为紧凑入口，同时保留原生查看变更与撤销动作，不触碰 React 内部状态。

## 交互契约

- 仅处理包含两个及以上文件的原生变更卡片；单文件卡片保持原生样式。
- 支持界面设置中切换默认收起/展开；用户对单张卡片的手动展开或收起状态优先保留，即使该卡片流式更新期间暂时变为单文件后恢复多文件，仍找回之前的手动状态。
- 展开时复用原生展开按钮以呈现全部文件，停止增强时完整移除按钮并恢复原生列表。

## 模块与验证

- `ui/`：`file-changes.ts`、`file-changes.css`
- 校验命令：`files`、`multi-window`
