# 界面增强

本目录负责已核实本机显示连接上的每窗增强；运行管理不在此决定，提示词监测也不由界面托管。

## 模块与入口

| 目录 | 职责 |
| --- | --- |
| host/ | CDP 连接上的 Node 控制器、窗口任务、状态写入和采集会话 |
| statistics/ | HUD、聊天绑定、格式化及 collector/ 本地采集器 |
| reading/ | 正文宽度与设置命令 |
| file_changes/ | 多文件列表默认收起及展开状态 |
| appearance/ | Custom 配色与可读前景 |

采集器源自 codex-token-hud v1.3.0-beta.8，版本和 MIT 许可见 [VERSION](statistics/collector/VERSION) / [LICENSE](statistics/collector/LICENSE)；稳定旧 collector 命令和许可位置继续保留。

## 统计口径与关联

- HUD 只展示最近已完成响应的均速、输入缓存比例和统计时间；缺失显示 ASCII `-`，不展示返回模型。
- 速度为整次输出 token 除以已知请求边界至响应用量记录的耗时，包含等待、推理和记录开销，排除已知工具执行。它不是逐 token 实时解码速度。
- 不以单个 item 起点配整次用量，不重采恢复的旧累计值，不设置经验速率上限；边界不完整则不计速。输出用量包括推理和工具调用 token。
- 缓存为 cached_input_tokens / input_tokens，相对时间表示统计生成时间。采集心跳超过 6 秒视为未连接，统计满 15 分钟视为过期。
- 优先主输入区的正式聊天 ID。临时 ID 仅在标题与本地索引唯一精确匹配时回退；不借用其他窗口或子代理数据。新轮次、错误绑定和旧 generation 不沿用结果。

## 页面与偏好

点击 HUD 打开宽度滑杆，最高 1600px、步长 16px，即时预览并保存；字号随原生输入区控件。主/侧聊天和子代理受各自面板宽度约束，输入框不变。Chat 模式仅沿用宽度，文档与空白页保持原生。

问题卡片、完整视图浮动输入区出现时隐藏 HUD 并关闭滑杆，退出恢复；无唯一主输入区、未知布局或空间不足也隐藏。多文件默认 0 行，可展开全部/再次收起；同卡片的手动展开保留，新卡片默认收起。单文件标题和查看变更/撤销入口保持原生，停止增强恢复列表。

Custom 配色仅修正自定义色下的消息气泡和输入框按钮，选择可读黑白前景，预设色保持原生。标签跟随 Codex 页面语言，未声明时才回退启动语言；支持英文/简体中文，其他语言回退英文。

## 故障隔离与持久状态

每个窗口拥有自己的 selection/metrics、采集器及清理。页面退出或连接结束才移除整窗增强；采集器退出只使本窗口统计不可用，按退避和滚动一分钟最多三次启动预算恢复，保留原 HUD、宽度、文件列表与配色。接收新数据须匹配当前采集 PID、启动后的心跳及聊天/generation。

宽度、配色偏好由 platform/settings/ 在同一锁内合并；读取失败保持最后有效值。文件展开状态和统计属于各自窗口，偏好可以安全共享。

## 验证

从项目根按改动运行 scripts/check.py 的 `metrics`、`collector-session`、`composer`、`width`、`files`、`accent` 或 `multi-window`；需要依赖路径时用 `--dependencies .runtime/token-hud/embedded/settings.json`，只读取依赖字段。

这些检查使用合成数据和独立浏览器，不连接或重启现用 Codex。真实布局、DPI 与长期表现的当前验收状态在本机 PROJECT.md 维护。
